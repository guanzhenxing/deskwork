## 1. 使用场景（功能为之服务的四件事）

1. **从资料到交付**：用户把工作资料导入资料库，建项目任务并勾选资料范围、专家与技能，在会话中产出 Word 工作副本，人工修改定稿后导出交付。半年后重新打开该任务，引用的资料修订与产物原样不变。
2. **把重复工作做成技能**：周报、评审清单等固定流程定义为技能（结构化定义编译为引擎可用的自适应技能），需要时在会话内用斜杠命令调用，配合连接器取数。
3. **个人知识沉淀**：全部文档集中进资料库，全文检索，引用可回溯到原文位置；用量摘要显示每个会话的模型花费。
4. **组织采用（企业版，闸门 G1 后）**：员工已在用个人版，公司部署控制平面后同一客户端改用公司账号登录，组织技能与专家出现在目录中，操作审计自动上送，危险操作按组织策略审批。

## 2. 概念词汇

| 词汇                 | 定义                                                                                                       |
| -------------------- | ---------------------------------------------------------------------------------------------------------- |
| 工作区               | 一份 home 内的全部产品数据：资料与修订、技能、专家、任务与会话引用、设置；可整体导出迁移                     |
| 资料 / 修订          | 导入资料库的文件及其历次内容版本；引用一律钉死到具体修订，源文件更新不改变历史引用                           |
| 项目 / 任务          | 项目聚合引用（不复制数据本体）；任务 = 会话 + 能力集快照（专家、技能、连接器、资料范围）                     |
| 会话                 | DSH 引擎的对话与执行单元；任务内的会话共享任务的能力快照                                                   |
| 技能                 | 编译为 DSH 自适应 Skill 的能力包；带来源范围（个人 / 组织）                                                 |
| 专家                 | 人设 + 能力引用集 + 组合技能的复合定义；发布冻结后不可变                                                   |
| 连接器 / 子工具      | MCP 服务及其提供的单个工具；每个子工具有风险分级                                                           |
| 风险分级             | read（只读免确认）/ write（记录执行）/ dangerous（执行前必须经确认）                                       |
| 交付物 / 工作副本     | 会话产出的可编辑文件为工作副本；定稿导出为权威文件并登记台账                                               |
| 内核                 | 身份 / 权限 / 审计三项基础服务，全部模块经它消费；用户可见部分为确认对话框、审计查询、用量摘要、模型槽位设置 |
| 控制平面（企业版）    | 组织自管的服务端：身份、策略、目录、审计汇集、模型网关；独立部署，客户端只以出站连接访问                     |

## 3. 模块功能明细

## 6. 用户可见的"不做"清单

1. 无画布/固定流程编排界面（引擎的 Agent 循环即编排）；
2. 无多人实时协同编辑（至托管版为止，组织共享的是目录、策略与审计，不是共同编辑）；
3. 无移动端；
4. 本地版无配额、无计费、无云端备份；
5. 客户端不内置常驻服务端组件（企业版的服务端是独立部署的控制平面）。
